# GlucoWAVE: Non-Invasive Glucose Monitoring

## Project Overview

GlucoWAVE is an engineering research project exploring radio-frequency (RF) antenna technology for non-invasive glucose monitoring. The project uses CST Studio Suite to design and simulate a microstrip patch antenna and an FSS-related structure, with the aim of studying their electromagnetic performance.

## Objectives

- Design and simulate a microstrip patch antenna using CST Studio Suite.
- Analyse antenna response using S-parameters and far-field characteristics.
- Investigate an FSS-related structure for potential antenna performance enhancement.
- Develop an AMC-based configuration and compare it with FSS in future work.

## Technology Used

- **Simulation software:** CST Studio Suite
- **Design approach:** Electromagnetic modelling and simulation
- **Analysis:** Resonant frequency, S-parameters, and far-field performance

## Current Project Status

The patch antenna and FSS-related structure have been modelled and simulated. AMC design and comparative evaluation remain future work.

## Important Note

GlucoWAVE is an early-stage engineering research project. The current antenna simulations do not establish glucose-monitoring accuracy or clinical validity. Glucose or HbA1c estimation would require suitable reference measurements, calibration, and independent validation.
